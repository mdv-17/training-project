# Training project information website

A small static website describing an in-development training and recovery application.

## Before presenting this to Garmin or inviting testers

- Replace the contact email placeholders in `index.html`, `privacy.html` and `imprint.html`.
- Complete the legal operator details and any required postal address in `privacy.html` and `imprint.html`.
- Verify the privacy notice accurately reflects the actual hosting, future Garmin API access, processors, consent, storage and deletion processes.
- Remove the draft notices only when those checks are complete.
- Never put Garmin API keys or real users' health data in this public repository.

The site currently only describes planned functionality. It contains no Garmin integration or login.
