Training and recovery

I’m building a running and strength planner for a small group of invited Garmin users.

Planned features

With each participant’s consent, the app would use Garmin’s APIs to support their training:

  • The Activity API would track completed runs and strength sessions, including recorded sets where available.
  • The Health API would help adjust upcoming sessions using sleep, resting heart rate and HRV trends.
  • Participants could edit suggested workouts and send them through the Training API to Garmin Connect for use on a compatible watch.

Private beta

The beta is planned and depends on Garmin API access. This information website does not connect to Garmin or collect training data.

I plan to offer the beta free of charge. I may invite more participants after reviewing feedback from the initial group. I have no current plans to charge for access.
