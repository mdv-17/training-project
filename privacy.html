Planned private beta

The planned free beta would use connected activity data to track completed runs, strength sessions and recorded sets where available. Sleep, resting heart rate and HRV trends would help adjust upcoming sessions. Participants could edit workouts and choose to send them to Garmin Connect for use on a compatible watch. These connections require participant consent.

Application hosting and access

The current training application uses OpenAI sign-in and runs on Cloudflare, with account-linked records stored in Cloudflare D1. Garmin supplies connected activity and recovery data. Connection credentials and optional calendar links are encrypted on the server.

Training suggestions are calculated by application rules. The current application does not call a generative AI API for these suggestions. It also exposes an optional assistant connection: using that connection can make training data available to OpenAI. This access must be explained separately before participants enable it.

Disconnecting Garmin stops future API imports but keeps imported history. The application’s “Delete all data” control removes the account’s application records and saved connections from active storage. It does not delete the participant’s Garmin or OpenAI account.
