About this website

This is a public information page for a training application in development. It has no user accounts, contact form or active Garmin connection. It does not collect Garmin activity or health data.

Hosting and technical data

The website is hosted using GitHub Pages, a service from GitHub, Inc. When you visit it, GitHub may process technical information such as an IP address and browser data to deliver and secure the website. More information is available in GitHub's privacy statement.

The website operator uses hosting to make this page available. The site itself uses no analytics service or advertising trackers and sets no first-party tracking cookies.

Contact

If you contact the operator by email, your message and contact details are used to respond to your request. They are not used for marketing.

Planned private beta

The planned free beta would invite a small group of Garmin users. With consent, the Activity API would supply completed runs, strength sessions and recorded sets where available. Health API data would include sleep, resting heart rate and HRV trends to adjust suggested sessions. Participants could edit workouts and send them to Garmin Connect through the Training API for a compatible watch.

This website does not process those records. Before participants connect, a beta privacy notice must identify the actual hosting and other processors, any international transfers, the legal bases for activity and health data, retention periods, and how to withdraw consent or delete data.
