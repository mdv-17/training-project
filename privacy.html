Scope and development status

This notice concerns the Training application. The current version is an owner-only prototype. Access for invited users and workout publishing through Garmin’s Training API are planned and are not yet enabled.

Data and purposes

The application links records to a signed-in account. It processes profile details and training preferences; connected Garmin activities, including runs, strength sessions and recorded sets, repetitions, weights and durations where available; and recovery information such as sleep, resting heart rate, HRV and activity load. Optional measurements, check-ins and published calendar sessions support planning and progress tracking.

These records are used to display training history, calculate exercise progression and suggest workouts around running and recovery. Connection credentials and tokens allow authorized imports; optional private calendar links allow schedule imports. Credentials and calendar links are encrypted on the server.

The planned workout-publishing feature will send only workouts selected by the user to Garmin Connect for a compatible device. It will require authorization and consent to transfer those workouts to Garmin. See Garmin Connect’s privacy notice.

Service providers and sharing

Garmin supplies authorized activity and recovery data and will receive workouts when publishing is enabled. OpenAI provides the Sites platform and account sign-in. Cloudflare provides application execution and storage, including Cloudflare D1 for account-linked records. These services support delivery of the application and processing of its data.

Microsoft Outlook handles email enquiries and data-rights requests. Microsoft receives the message and any information included in it. Do not send credentials or unnecessary health records by email.

Garmin data is not sold. It is not shared for advertising or data brokerage. Necessary sharing is limited to the services described here, user-authorized Garmin transfers, and disclosures required by law. Other participants do not have access to a user’s private records.

AI transparency

Workout suggestions are calculated by application rules. The current application code does not send workout or health records to a generative AI model for analysis. Its optional assistant connector can trigger a server-side Garmin refresh and return the last successful import timestamp; it does not expose activity or health records through its tools.

Garmin data and information derived from it must not be used to train, evaluate or improve AI models. Developing the software with an AI coding assistant does not require submitting real user records or API secrets to that assistant.

Any future AI analysis of Garmin records will remain disabled until permitted by the applicable Garmin terms and covered by a specific explanation of the provider, data and purpose. It would require separate explicit opt-in consent and an accessible withdrawal control. It is not part of the current service.

Consent and connection controls

In the current prototype, Settings allows the owner to disconnect the Personal API connection and remove the separate calendar link. Disconnecting stops API imports; removing the calendar link stops calendar imports. Disconnecting alone retains imported history. Delete all data in My Account removes records and saved connections from active application storage.

The planned multi-user integration will use Garmin’s authorization screen rather than require participants to supply Personal API keys. Before collecting participant health data, the app must implement explicit consent for the specified purposes under Articles 6(1)(a) and 9(2)(a) GDPR. This participant consent process is not yet implemented.

You can withdraw consent by contacting the developer at the address above. Where applicable, you can also revoke the app’s permissions in Garmin Connect. Withdrawal does not affect the lawfulness of processing before withdrawal. Withdrawing access to necessary data prevents the related import or recommendation features from operating.

Access, corrections, export and deletion

You can view records in the application and edit profile information and supported records there. Corrections to imported records are kept within the application and do not change Garmin Connect.

To request access to all application-held personal data, correct records that cannot be edited in the interface, or request a machine-readable export, email the developer. There is currently no self-service export button. You can delete active application data through My Account or request deletion by email. Deleting application data does not delete your Garmin or OpenAI account.

Applicable rights also include restriction of processing, portability and objection. You may complain to a data protection authority, including the authority in your place of residence or the Baden-Württemberg data protection authority.

Retention and remaining arrangements

Current prototype records remain in active storage until deleted; there is no automatic inactivity-deletion schedule. Removing a connection does not automatically erase past records. Provider backups and operational logs may have separate retention periods; their applicable periods and deletion handling still require confirmation.

Provider processing may involve locations outside the European Economic Area. The applicable processing agreements, locations and international-transfer safeguards must be confirmed before invited-user access begins. This notice does not claim that hosting is restricted to the EU.

Invited-user access will remain closed until these arrangements and the health-data consent process are completed. This notice describes the present prototype and planned features; it is not confirmation that the beta is ready to launch.
